# Dossiê Criminal — vídeos

Séries em vídeo sobre cada Grand Theft Auto, feitas para o site **https://www.gtatimeline.app** (seção Vídeos) e para as redes.

- `indice.json` — a lista que o site lê
- `<jogo>/NN-id.mp4` — vídeos verticais (720x1280) e `<jogo>/youtube-16x9.mp4` — episódio completo
- Imagens dos jogos: Rockstar Games / GTA Wiki (Fandom). Trilha e narração originais.
